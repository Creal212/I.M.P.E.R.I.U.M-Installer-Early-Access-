# 0.2.3 — Main path compatibility

Source-record date: **2026-09-10**. This is the date recorded in the publisher's note, not an inferred public upload date.

Historical note record. Availability of an archived binary is not asserted.

## Recorded changes

- Older imports no longer report lost Main linkage solely because a newer optional folder ID is missing; the saved path is checked directly.
- Stable snapshot identity prevents false changed-registration reports for older Clone records.
- Clone scans remain available when Main patch eligibility needs attention; a separate refresh failure does not discard completed findings.
- Main checks reject substituted junctions/symbolic links, while older patches retain conflict, order and reviewed rollback checks.
- Explicit excluded-file review works at the unchanged recorded Main path without accepting unrelated or mismatched folders.

## Data and provenance

Normal installer upgrades replace program files and preserve app data, Main projects and scratch work. Keep independent backups; uninstalling is not complete erasure.
