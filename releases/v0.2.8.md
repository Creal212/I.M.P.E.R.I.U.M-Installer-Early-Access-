# 0.2.8 — Artifact integrity and recovery

Source-record date: **2026-09-13**. This is the date recorded in the publisher's note, not an inferred public upload date.

Historical note record. Availability of an archived binary is not asserted.

## Recorded changes

- Compatible OpenAI, Gemini and xAI API connections support original-image editing with bounded input/output checks.
- Retained edits with unproven acceptance can be reviewed and kept/reverted without rewriting the original verification result.
- Encoded secrets, key containers and duplicate JSON fields receive stronger inspection; unsupported decoding/media retain coverage limitations.
- Missing Saved States, stale approvals and recovery cannot silently weaken Clone/Main boundaries.
- Workspace preserves requested native editing intent, long Windows paths and authenticated recovery journals.
- File-only replies, selected image versions and document/storyboard completion require actual stored evidence; provider errors redact private request material.
- Shadow preview follows the reachable frontend entry and exposes real unresolved dependencies rather than unused modules.

## Data and provenance

Normal installer upgrades replace program files and preserve app data, Main projects and scratch work. Keep independent backups; uninstalling is not complete erasure.
