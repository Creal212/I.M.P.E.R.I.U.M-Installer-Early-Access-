# v0.2.34 — 2026-11-21

## Added

- The installed app asks for a purchased license key before it will do any work. The key is checked with the Axiom license service and bound to this PC's Windows id.

## Installer / data

- App binaries and resources in the install directory are replaced on upgrade.
- User data under `%USERPROFILE%\.aivault\` (or `AIVAULT_HOME`) is **not** deleted.
- A license file is written only after the license service accepts the key for this PC. Copying that file to another PC does not unlock the app.
- This remains an unsigned manual early-access installer. Authenticode, fresh-device setup and real-data upgrade qualification are not represented as passed.
- Version 0.2.33 and earlier do not include this license gate.
