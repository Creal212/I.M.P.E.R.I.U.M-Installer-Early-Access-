# v0.2.31 — 2026-10-06

## Added

- Optional release discovery on launch with a persistent local opt-out and an unobtrusive review notice.
- Main-window-only verified manual installer download, bound to the reviewed version, byte count and SHA-256, with a user-selected Save location.

## Changed

- About us now provides Check now, readable release notes, current native app version, latest published version and clear retry/error states.
- Privacy & policies and offline bundled privacy documents explain GitHub connection data, launch-check choices and the unsigned manual update boundary.

## Removed

- The visible placeholder signed-update scan and Install & Restart action; no unsigned installer is launched automatically.

## Fixed

- Checks now contact the official stable GitHub release feed instead of silently returning not configured.
- Native version comparison, exact installer/checksum metadata validation, pre-request redirect allowlisting and bounded downloads reject malformed or changed offers.
- Installer saves refuse existing, raced or aliased destinations without replacing user files; failed temporary publication is cleaned up.
- A successful manual retry refreshes the launch notice and removes stale network errors.

## Installer / data

- App binaries/resources in the install directory are replaced on upgrade.
- User data under `%USERPROFILE%\.aivault\` (or `AIVAULT_HOME`) is **not** deleted.
- Scratch vaults under `Documents\Aegis 589\` are **not** deleted.

- This Windows x64 release remains unsigned manual early access. Save your work and close the app before manually running setup; checksum verification is not publisher signing.
- Existing installed clients through 0.2.30 need one manual bootstrap install to receive the new checker. Website metadata cannot update their compiled placeholder.
- No model/provider permissions, project data, credentials or paid actions are changed. Saved appearance and other settings remain intact.
- Synthetic installer lifecycle checks and native HTTP/download tests do not qualify clean-device installation, SmartScreen/UAC, live model/provider calls or user-profile installation.

Published unsigned early-access installer; exact public-download byte count and SHA-256 match the reviewed local package.
