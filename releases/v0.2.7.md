# 0.2.7 — Persistent setup and provider login

Source-record date: **2026-09-11**. This is the date recorded in the publisher's note, not an inferred public upload date.

Historical note record. Availability of an archived binary is not asserted.

## Recorded changes

- Native setup persists in the background with Pause/Resume and public native-model product guidance.
- Codex subscription text tasks use app HTTPS and scoped tools without Docker/native coding-runtime setup.
- Provider cards separate account sign-in from task/media availability.
- Navigation no longer cancels downloads; partial data is retained and official hashes verified before use.
- Windows engine checks cover runtime, grammar, CUDA and API readiness, with actionable recovery.
- Gemini/Grok sign-in and stale reconnection state gain visible progress/failure guidance.
- Concurrent app windows cannot start competing setup/download jobs; installation records and verified files stay consistent.
