# v0.2.30 — 2026-10-06

## Added

- Book Cream and Book White bring the Book of Blocks paper palette into the supervised workspace, with solid code and terminal surfaces, contents-style rails and chapter tabs.
- Original animated drafting-compass and routing sketches live in reserved notebook margins. They pause offscreen and respect reduced motion, the operating system preference and the existing motion control.

## Changed

- New profiles open in Book Cream. Existing saved palettes, System appearance, typography, density and motion preferences remain available and are preserved.
- Notebook headings use the app's existing locally bundled, licensed serif fonts; editor and terminal code keep their monospace typography.

## Removed

- (none)

## Fixed

- Cached System appearance is respected while native preferences load. First-paint, theme persistence, paper-ink contrast and keyboard-focus regressions are included in the mandatory release gate.
- Code bracket pairs use the notebook's semantic inks instead of the stock light editor's low-contrast green.

## Installer / data

- App binaries/resources in the install directory are replaced on upgrade.
- User data under `%USERPROFILE%\.aivault\` (or `AIVAULT_HOME`) is **not** deleted.
- Scratch vaults under `Documents\Aegis 589\` are **not** deleted.
- Configurations, projects, sealed stores and receipts remain outside the installation tree. This update adds no new telemetry, provider, permission or paid action; offline legal documents and existing local/cloud boundaries are unchanged.
- This is an unsigned Windows manual early-access installer. Signing, clean-device installation, SmartScreen/UAC behavior and live model/provider behavior are separate qualifications.

Published unsigned early-access installer; exact public-download byte count and SHA-256 match the reviewed local package.
