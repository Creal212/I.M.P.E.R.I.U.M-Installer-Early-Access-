## Recorded changes

### A workspace with more character

- Six new coordinated color collections—Verdigris, Midnight Atelier, Garnet, Travertine, Porcelain and Tidal—join Obsidian and Parchment. Colors carry through app surfaces, the code editor and terminal.
- Home's seal, signature line and headline gain coordinated motion. Reduced-motion choices apply from startup, and inactive artwork pauses.
- Agent 589 brings the portfolio character into the app as a local guide. Drag it, let it perch on panels, choose a tiny size, keep it quietly wandering or switch it off under Settings → Agent 589 guide. It is on by default and does not start a model or send questions to a server.
- Meet the developer in About includes rotating, prewritten portrait asides when Agent 589 approaches. The deck avoids frequent repeats and respects quiet/hidden states; it is playful character dialogue, not a performance claim.

### Reliability improvements

- Theme validation, startup restoration and Settings recognize all eight palettes.
- Guide shortcuts reopen the intended Settings area while preserving unsaved changes.
- Three explicit desktop command grants used by clone-permission controls and confirmed State 0 recovery are restored. This corrects missing IPC permission wiring; existing project checks, environment boundaries and recovery confirmation remain required.

## Data and provenance

The installer replaces program files. Separate user data, projects, Main folders, downloaded native models and saved preferences remain separate from that program-file update. Keep backups and save work before upgrading; real-data upgrade behavior was not newly evaluated here.

**Lite, Mini, Agent 589 and Core remain optional downloads in Settings → Agent 589.** No model is bundled, and installing this update does not initiate a new model download. Existing model setup and startup preferences remain in effect. No new portable package is included. The old 0.2.15 Mini preview remains its original, separately labeled historical build. WebView2 may require internet if missing; optional model and engine preparation also needs internet before offline inference is available.
