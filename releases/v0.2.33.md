## Fixed

- Windows provider API keys now use a user-bound DPAPI master key. Legacy local keys migrate atomically without changing existing encrypted credentials; corrupt/missing stores fail closed, writes serialize across app windows, and linked secret files are refused.
- Updated DOMPurify, source-map-js, rustls and owned ZIP parsers for current security advisories. Windows updater accepts the published NSIS executable format without the unused legacy ZIP extractor.

## Installer / data

- App binaries/resources in the install directory are replaced on upgrade.
- Existing Windows API-key master keys migrate to a Windows-user-protected format on first access. Older app versions cannot read that protected format; another account/machine requires provider reauthentication. This does not migrate or rotate actual provider credentials.
- User data under `%USERPROFILE%\.aivault\` (or `AIVAULT_HOME`) is **not** deleted.
- This remains an unsigned manual early-access installer. Authenticode, fresh-device setup and real-data upgrade qualification are not represented as passed; no automatic updater feed is activated.
- Scratch vaults under `Documents\Aegis 589\` are **not** deleted.
