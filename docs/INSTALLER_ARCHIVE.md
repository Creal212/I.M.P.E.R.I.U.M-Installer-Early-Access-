## Version notes without installers

The [complete change history](../CHANGELOG.md) includes earlier development versions whose binaries are not offered. Notes, Git tags, repository ZIPs and GitHub-generated source archives are not application installers.

## Choosing an older version

Earlier versions do not contain later fixes or interface updates. Read the notes and known limitations for the exact version before installing. Keep independent project backups, close the app before changing versions, and do not assume an older version supports settings or data written by a newer one. Downgrades have not been qualified.

Preconfigured previews have their own version and setup requirements. They remain clearly labeled as previews; archive membership does not improve their validation status.
