## Choosing an older version

Older versions do not include newer fixes. The 0.2.15 Mini ZIP remains an older preview; it does not contain 0.2.17 or 0.2.18 changes. Downgrades are not qualified. Save work, close the app and keep independent backups. Previews retain their own setup and validation limits.
