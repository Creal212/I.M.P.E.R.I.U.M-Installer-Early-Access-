# Known limitations

- AI may misunderstand requests, omit steps, invent facts, produce incorrect code, lose context or violate requested formatting. A response is not a correctness pass.
- CPU Mini suits short text assistance. Complex coding, model self-identification and first-draft planning remain limited in the built evaluation line.
- 0.2.16 remains a source-only milestone. Native-model quality evaluation, including its QA format variation, is paused and incomplete. The 0.2.17 interface and response-handling changes do not establish model intelligence or correctness.
- Provider login, API access, task execution and media entitlement differ. Some connections require the provider's own supported setup.
- Security checks cover inspected material and recorded rules. Unsupported, missing or deferred material can limit coverage.
- Shadow Verify is experimental; stand-ins do not validate real production services.
- Artifacts need actual verified bytes. Unsupported formats or missing engines may prevent delivery.
- Apply/rollback can stop on conflicts, changed folder identity, missing evidence or overlapping edits.
- Optional larger models may be impractical on low-memory hardware; no simultaneous-model guarantee is made.
- The installer is an early-access release. Fresh-device installation, real-data upgrades and full real-account authentication coverage are incomplete; read its [exact signing and package status](DOWNLOADS.md). Synthetic installer checks are not physical-device qualification.
- The Mini preconfigured preview is packaging-checked but unlaunched; actual model startup, first-run and relocation are untested. Regular/Core portable editions are planned. An archive is not proof of portable runtime behavior.
