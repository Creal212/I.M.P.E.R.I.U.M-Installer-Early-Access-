# Support

Contact **[Primepeace2003@gmail.com](mailto:Primepeace2003@gmail.com)**. Publisher: Axiom Risk, based in Minnesota.

For community questions, ordinary bugs, ideas and project feedback, [join the Imperium Discord](https://discord.gg/WZCxhjPwE). Participation is optional; email is still available. Community posts and attachments may be visible to other members, so share only material you are authorized to disclose.

Include the app/Windows versions, affected environment and provider type, expected and actual behavior, short reproduction steps and a redacted error or screenshot. Note whether the task report says failed, incomplete or finished and whether a selected local model was actually running.

Do not send passwords, API keys, device codes, private project contents or unredacted logs. Public GitHub issues and community channels are not private support inboxes. Use [private security reporting](SECURITY.md) for vulnerabilities; do not post exploitable details in Discord or public issues.

Check [Downloads](DOWNLOADS.md) and [Known limitations](KNOWN_LIMITATIONS.md). No response-time guarantee or paid support service level is established here.
