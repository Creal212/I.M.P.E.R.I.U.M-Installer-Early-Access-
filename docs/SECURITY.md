# Report a security issue

Email **[Primepeace2003@gmail.com](mailto:Primepeace2003@gmail.com)** with the subject **I.M.P.E.R.I.U.M security report**.

Include the affected version/platform, concise impact and minimal reproduction using harmless sample data. Identify the relevant boundary: Clone/Main, provider, artifact, patch, scan or installer.

Do not send real credentials, production secrets, personal records, full private repositories or unredacted logs. Do not post exploitable details or sensitive files publicly. Email is not presented as a dedicated encrypted portal; ask how to share sensitive material before sending it.

Test only systems and material you own or are authorized to assess. This page does not authorize testing other users or third-party providers. Stop if another person's data is encountered; avoid retaining it and explain the circumstance privately.

No guaranteed response time, bounty, safe-harbor program or long-term-support schedule is promised. Ordinary bugs can use [Support](SUPPORT.md). For a suspicious installer, retain its URL/hash, do not run it, and compare with the exact official release identity. Do not disable antivirus to bypass the concern.
